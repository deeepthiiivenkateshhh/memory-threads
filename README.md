Key Features:

1. Multilingual Regional Voice Support: Full native language prompts, text-to-speech, and progressive hint guidance in Assamese, Mizo, Nagamese, Khasi, and English.
2. Interactive Cognitive Activities:

* Personal Memory Recall with visual context anchors
* Folk Song Completion games
* Photo Pair Matching activities

3. Accessibility-First Design: High contrast mode, dynamic font scaling (14px to 32px), adjustable speech rate, and speech tone controls.
4. Caregiver Portal and Telemetry:

* Interactive Memory Relationship Graph
* Real-time voice confidence and hesitation tracking
* One-click PDF report export and CSV data download
